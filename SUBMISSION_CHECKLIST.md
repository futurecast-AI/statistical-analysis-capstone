# Statistical capstone submission checklist

Author: AI Foundations (Edward Hickman)

## Required files

- `analysis.ipynb` — executed, with statistics, three inline figures, primary
  hypotheses/statistic/p-value, comparison notes, and a final five-sentence summary.
- `module_summary.pdf` — report with every required heading and citations.
- `student-por.csv` — unchanged real UCI dataset, 649 × 33, beside the notebook.
- `requirements.txt` — generated using actual `pip freeze > requirements.txt`.

## Supporting materials

- `module_summary.docx` and `module_summary.md` are editable report versions.
- `outputs/` contains saved figures, tables, runtime versions and numerical results.
- `ANALYSIS_PLAN.md` explains decisions, assumptions and decision timing.
- `data_provenance.md` records the source, attribution, license and input hash.
- `tests/` and `scripts/` support verification and document construction.

## Before submitting

- Read the notebook and report, understand the test and limitations, and revise
  the wording to reflect your understanding. Replit AI assistance is disclosed;
  confirm that the course permits this use.
- Check whether the instructor wants a ZIP upload, a GitHub link, or both.
  The provided assignment lists the four required files; it does not mandate GitHub.
- If using a repository link before merging, point reviewers to the completed
  development branch/PR rather than the initial README on `main`.
- Instructor and due date were not supplied and were not invented.
- The report reuses the supplied APA student-paper template. Word styles retain
  Arial; PDF export uses metrically compatible Liberation Sans.
- A ZIP includes files but not the repository's branch/commit history.
- The notebook runs offline after dependencies are installed.
